# APSAD Lebanon — Heritage NGO brand site

Next.js 15 (App Router, `src/` dir, port 9002) · Tailwind 3 + shadcn/ui · Genkit AI chatbot.

## Design Context

- **PRODUCT.md** (project root) — register (`brand`), audience, brand personality, anti-references, design principles. Read it before any UI work.
- **DESIGN.md** (project root) — the visual system: tokens, typography, named rules, do's/don'ts. Tokens live as HSL custom properties in `src/app/globals.css`.
- Design work goes through the `/impeccable` skill; live-variant mode is preconfigured in `.impeccable/live/config.json`.
